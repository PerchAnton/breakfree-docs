# BreakFree Docs icon

<img src="breakfree-docs.webp" alt="Approved BreakFree Docs icon" width="160" height="160">

This is the owner-approved Docs design: portrait document pages, text lines and a rainbow ribbon on an aubergine app tile. It is distinct from the general Office, Sheets and Slides marks.

`breakfree-docs.webp` is a 320 × 320 display derivative of the approved 1254 × 1254 raster artwork. It is for README and web display, not a vector master or a complete operating-system icon bundle. It retains the artwork's opaque exterior; no transparency is implied. Use the original artwork when preparing future high-resolution packaging.

See the [shared brand guide](https://github.com/PerchAnton/breakfree-office/blob/main/BRAND.md). Asset licensing remains an owner decision.
