# Contributing to BreakFree Docs

Read the [shared contribution guide](https://github.com/PerchAnton/breakfree-office/blob/main/CONTRIBUTING.md) and [Code of Conduct](https://github.com/PerchAnton/breakfree-office/blob/main/CODE_OF_CONDUCT.md).

Use this repository for writing workflows, the document model, editing, persistence and DOCX investigations. Suite-wide identity and shared policy belong in [BreakFree Office](https://github.com/PerchAnton/breakfree-office).

Start with [ROADMAP.md](ROADMAP.md) and [the first milestone](docs/REQUIREMENTS.md). Discuss major architecture or dependencies in an issue before implementing them. Licensing must be agreed with the owner before substantive third-party code is accepted.

Keep pull requests focused. Explain what changed, the intended user outcome and the checks actually run. Use synthetic documents, never customer data, private correspondence or unlicensed assets. Build and test commands do not exist yet; add them with the first working implementation.
